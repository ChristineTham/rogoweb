# Product Guidelines

## Visual Theme & Branding
- **Industrial VT100 Aesthetic**: The overarching aesthetic mimics the physical hardware of the DEC VT100 terminal. Use an industrial beige palette for the interface bezel and a pure black background `#000000` for the screen area with high-contrast P4 white (`#ebf0ff`) or orange (`#FE5000`) accents. Fonts should be monospace and terminal-inspired (e.g., VT323) to maintain the nostalgic atmosphere of the original hardware.

## UX Principles & Layout
- **Dense Information Architecture**: The dashboard is designed for power users and AI enthusiasts. Prioritize information density over negative space. The layout should simultaneously display the live `xterm.js` game feed, real-time Rogomatic bot statistics, inventory, and genetic pool status without requiring the user to navigate through multiple tabs.

## Tone of Voice
- **Nostalgic & Arcane**: All UI copy, tooltips, and system alerts should adopt the distinct, mysterious flavor of early dungeon crawlers. Use phrasing that matches the original game's personality (e.g., "The Gene Pool expands...", "A fatal error strikes you down!", "Your memory is preserved").
